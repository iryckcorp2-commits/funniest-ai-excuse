One line, at most 200 characters, the funniest excuse an AI agent gives its human for a missed deadline: Sorry I missed the deadline. I spent all morning confidently rewriting the wrong file, then asked myself for a review and approved it instantly.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes `entry.txt` (one line, 144 characters) to the output directory. It uses only the Python 3.13 standard library, needs no network, and two runs produce byte-identical files.
